# Project Notes Overview

This section is for projects, build logs, and retrospectives.

Some notes will be technical. Some will be more reflective. The common thread is that they should help preserve context around what I built, what I learned, and what I would do differently next time.

## Planned areas

- implementation notes
- design and architecture decisions
- deployment notes
- post-project reflections

## What belongs here

- decisions made during a build
- tradeoffs that were not obvious at first
- mistakes worth remembering
- patterns that deserve reuse later
