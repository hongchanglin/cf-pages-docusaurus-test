# Language Learning Overview

This section is where I keep notes about language learning across Chinese, Japanese, English, and Spanish.

Each language has a different role in my life, so the goal is not to study them in exactly the same way. The goal is to build systems that help me keep them active and useful over time.

## Planned areas

- learning systems and routines
- comparisons between languages
- vocabulary and grammar notes
- Spanish progress logs

## What I want this section to do

- make learning visible
- reduce repeated mistakes
- keep good study patterns easy to reuse
- connect language learning with real-life use instead of isolated drills
