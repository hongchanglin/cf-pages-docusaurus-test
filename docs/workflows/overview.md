# Workflow Overview

This section is for the systems behind the work.

That includes how I document things, how I review information, how I keep notes useful, and how I turn one-off effort into something I can build on later.

## Planned areas

- note-taking systems
- review and learning loops
- troubleshooting playbooks
- personal operating habits

## Guiding idea

A good workflow should make useful work easier to repeat.

If a process only works when I have extra motivation, it is probably not a good long-term workflow yet.
